# NombreDelProyecto-Pendiente

Aplicación móvil desarrollada en Android Studio como proyecto final de la asignatura Programación Orientada a Objetos II.

## Tecnologías utilizadas
- Kotlin
- Android Studio
- Jetpack Compose
- Firebase (opcional)
- Git y GitHub

## Objetivo del proyecto
Desarrollar una aplicación móvil aplicando los principios de Programación Orientada a Objetos, buenas prácticas de desarrollo y diseño de interfaces modernas.
